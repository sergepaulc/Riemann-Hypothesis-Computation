# Riemann Hypothesis Computation — Version 1.0

This release accompanies the Version 1.0 paper, *A Computational Walk from Pair Correlation to Higher-Order Spectral Statistics of Zeta Zeros*.

## Included

- The paper in GitHub-compatible Markdown, with its eight publication figures.
- The three computational experiments, their recorded settings, derived input data, machine-readable reference results, and numerical tests.
- Reproduction commands that operate in isolated work directories and compare regenerated tables with the supplied reference values.
- Pinned Python dependencies, original-source download instructions, citation metadata, and license information.

## Packaging and rendering

The package omits earlier drafts, governance specifications, internal review material, and administrative history. Published numerical inputs and parameters are retained. Experiment 3's recorded random-seed namespace is stored as computational data rather than requiring an old narrative protocol. The supplementary Experiment 2 validator uses configurable paths instead of paths on the author's former working machine.

GitHub mathematics uses fenced `math` blocks and protected inline expressions. Upright real-part notation is written as `\mathrm{Re}`. The critical-strip expression, piecewise delimiters, mathematical table cells, and figure links have been checked. Unsupported image-size attributes have been removed from the GitHub Markdown.

The paper's scientific formulas and numerical results are unchanged.

## Validation scope

See [the validation record](docs/VALIDATION.md) for checks actually run. This is numerical and packaging validation, not external academic peer review.

The Experiment 1 runner reproduces the three full-sample pair-statistic calculations. The supplied archive contains the original finite-GUE/Poisson calibration outputs and configuration, but not a complete runnable generator for every calibration result. Those ensembles are therefore supplied as reference data, not advertised as freshly regenerated by the main command. The eight publication figure images are included; experiment diagnostic plots are regenerated by the available figure scripts.

This is a finite computational study, not a proof of the Riemann Hypothesis or an established higher-order law for zeta zeros.
