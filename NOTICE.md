# Notices and third-party data

The MIT license applies to original code and documentation in this repository. It does **not** grant rights in third-party source data, third-party publications, or attributed review records unless separately stated.

The raw zeta-zero tables used for provenance are published by Andrew M. Odlyzko. They are not redistributed in this public repository. The repository ships:

- a downloader pointing to the authoritative source;
- expected SHA-256 fingerprints for the exact source files used;
- checksum-locked derived unfolded coordinates and machine-readable results.

Users should cite the original data source and comply with any source-specific terms. Derived research artifacts are included to make the paper's computations directly reproducible without requiring the raw tables for the main reruns.

Historical frozen files may retain the internal project name `Project Montecito`; those names are preserved as provenance and do not identify the public GitHub repository.
