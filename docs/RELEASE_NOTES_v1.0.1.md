# Riemann-Hypothesis-Computation release v1.0.1

This is the first planned public GitHub release of the reproducibility repository accompanying _A Computational Walk from Pair Correlation to Higher-Order Spectral Statistics of Zeta Zeros_.

- The public repository name is `Riemann-Hypothesis-Computation`.
- The root folder, README, publishing instructions, package metadata, environment name, citation metadata, and URL-finalization workflow use that name.
- Immutable historical artifacts retain the internal name `Project Montecito` for provenance.

## Manuscript synchronization

- The repository paper directory is synchronized to manuscript draft v1.9.
- The paper directory includes all eight current figures, including the compact Experiment 3 summary figure.

## Scientific status

No frozen Experiment 1, 2, or 3 scientific result is changed by this public-name update. Experiment 3's corrected release, unit tests, independent collision validator, and uncertainty-scale records remain the controlling computational artifacts.
